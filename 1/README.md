## 2.2. Работа с файловой системой

### 2.2.1

> **В домашнем каталоге текущего пользователя создайте подкаталог `fruits`.**

```bash
mkdir fruits
```

### 2.2.2

> **Перейдите в корневой каталог. Из корневого каталога создайте в домашнем каталоге подкаталог `animals`.**

```bash
cd /
mkdir ~/animals
```

### 2.2.3

> **В каталоге корневой файловой системы, предназначенном для временных файлов, создайте пустой файл `temp`.**

```bash
touch /tmp/temp
```

### 2.2.4

> **Используя `echo` и перенаправление вывода, запишите в файл `temp` строку `Hello`. Второй такой командой допишите строку `world`. Откройте файл в `nano`, добавьте в конец три знака `!`, сохраните файл и выйдите из редактора.**

```bash
echo "Hello" > /tmp/temp
echo "world" >> /tmp/temp
nano /tmp/temp
```

### 2.2.5

> **Перейдите в каталог `fruits` и создайте в нём пустые файлы `apple`, `banana`, `pineaple`, `lion`, используя соединение команд при помощи `&&`.**

```bash
cd ~/fruits
touch apple && touch banana && touch pineaple && touch lion
```

### 2.2.6

> **Находясь в каталоге `fruits`, создайте в каталоге `animals` пустые файлы `cat.txt`, `dog.txt`, `elephant.txt` одной командой.**

```bash
touch ../animals/{cat,dog,elephant}.txt
```

### 2.2.7

> **Выведите все файлы каталога `fruits`, имена которых начинаются с буквы `a`.**

```bash
ls a*
```

### 2.2.8

> **Выведите все файлы каталога `fruits`, имена которых заканчиваются буквой `e`.**

```bash
ls *e
```

### 2.2.9

> **Выведите все файлы каталога `fruits`, имена которых содержат буквы `a` и `n`.**

```bash
printf '%s\n' * | grep 'a' | grep 'n'
```
или же
 
```bash
ls *a*n* *n*a* | sort -u
```
или же (после 2.5)

```bash
find . -maxdepth 1 -type f \(-name '*a*' -name '*n*'\) 
```
### 2.2.10

> **Скопируйте файл с учётными записями пользователей системы в домашний каталог текущего пользователя. Выведите количество строк в этом файле. В домашнем каталоге создайте символическую ссылку на этот файл. Определите номер inode этой ссылки.**

```bash
cp /etc/passwd ~/
wc -l ~/passwd
ln -s ~/passwd ~/passwd_link
ls -li ~/passwd_link
```

### 2.2.11

> **Выведите содержимое файла `/etc/issue` на экран.**

```bash
cat /etc/issue
```

### 2.2.12

> **Скопируйте файл `/etc/issue` в файл `apple` с заменой содержимого и выполните проверку.**

```bash
cp /etc/issue apple
cmp /etc/issue apple
```

### 2.2.13

> **Переместите файл `lion` в каталог `animals`.**

```bash
mv lion ~/animals/
```

### 2.2.14

> **Исправьте опечатку в имени файла `pineaple`.**


### 2.2.15

> **В домашнем каталоге создайте жёсткую ссылку на файл истории команд командной оболочки. Выведите информацию о количестве жёстких ссылок на этот файл.**

## 2.3. Механизм конвейеров

### 2.3.1

> **Выведите на экран отсортированный по алфавиту список пользователей операционной системы.**

```bash
cut -d: -f1 /etc/passwd | sort
```

### 2.3.2

> **Выведите на экран число пользователей, у которых командной оболочкой является Bash.**

```bash
cut -d: -f7 /etc/passwd | grep -c '/bash$'
```

### 2.3.3

> **Выведите только имена пользователей, использующих Bash, отсортировав их по алфавиту в обратном порядке.**

```bash
grep ':/bin/bash$' /etc/passwd | cut -d: -f1 | sort -r
```

### 2.3.4

> **Выведите имена пользователей и используемую ими командную оболочку в две колонки.**

```bash
cut -d: -f1,7 /etc/passwd | tr ':' '\t'
```

## 2.4. Получение прав суперпользователя

### 2.4.1

> **Выведите на экран содержимое файла с паролями пользователей, выполняя команду от имени текущего пользователя.**

```bash
cat /etc/shadow
```

### 2.4.2

> **Выведите список групп текущего пользователя. Определите, входит ли пользователь в группу администраторов. Если нет — завершите сеанс текущего пользователя, авторизуйтесь как `root` и добавьте пользователя в группу администраторов при помощи `usermod`.**

```bash
groups
```

### 2.4.3

> **Выполните команду из задания 2.4.1 от имени суперпользователя с помощью `sudo`.**

```bash
sudo cat /etc/shadow
```

### 2.4.4

> **Выведите список всех пользователей, входящих в группу администраторов.**

```bash
getent group sudo
```

### 2.4.5

> **Обновите список доступных пакетов, установите пакет `build-essential`. Проверьте версии установленных компиляторов и средств автоматизации сборки.**

```bash
sudo apt update
sudo apt install build-essential
gcc --version
g++ --version
make --version
```

## 2.5. Поиск файлов и каталогов

### 2.5.1

> **Изучите доступные опции утилиты `find`.**

```bash
man find
```

### 2.5.2

> **Найдите все файлы и каталоги, имя которых содержит подстроку `pass` с учётом регистра.**

```bash
cd ~/BOS/1
find . -name '*pass*'
```

### 2.5.3

> **Найдите все файлы и каталоги, имя которых содержит подстроку `pass` без учёта регистра.**

```bash
find . -iname '*pass*'
```

### 2.5.4

> **Найдите все файлы и каталоги, имя которых содержит подстроку `pass` с учётом регистра. Начните поиск с `/` и ограничьте глубину одним уровнем.**

```bash
find / -maxdepth 1 -name '*pass*'
```

### 2.5.5

> **Найдите все файлы и каталоги, имена которых оканчиваются на `.bin`. Выполните поиск в `/home` и всех его подкаталогах.**

```bash
find /home -name '*.bin'
```

### 2.5.6

> **Найдите все обычные файлы и только их, имена которых оканчиваются на `.bak`, и удалите их.**

```bash
find . -type f -name '*.bak'
find . -type f -name '*.bak' -delete
```

### 2.5.7

> **Найдите все обычные файлы и только их, имена которых оканчиваются на `.txt` или `.sh`.**

```bash
find . -type f \( -name '*.txt' -o -name '*.sh' \)
```

### 2.5.8

> **Найдите все обычные файлы в текущем каталоге и всех его подкаталогах. Для каждого файла выведите только: имя файла без пути, имя владельца, имя группы владельца, количество жёстких ссылок и размер в байтах.**

```bash
find . -type f -printf '%f %u %g %n %s\n'
```

### 2.5.9

> **Найдите все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог в результат не включайте.**

```bash
find . -mindepth 1 -type d -empty
```

### 2.5.10

> **Найдите и удалите все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог сохраните.**

```bash
find . -mindepth 1 -type d -empty
find . -depth -mindepth 1 -type d -empty -delete
```

### 2.5.11

> **Найдите и удалите все пустые обычные файлы и только их. Пустым считайте файл размером `0` байт.**

```bash
find . -type f -size 0
find . -type f -size 0 -delete
```

### 2.5.12

> **Найдите все обычные файлы в текущем каталоге и всех его подкаталогах, у которых количество жёстких ссылок больше одной.**

```bash
find . -type f -links +1
```

### 2.5.13

> **Найдите все файлы и каталоги в `/etc` и его подкаталогах, не принадлежащие пользователю `root`.**

```bash
find /etc ! -user root
```

### 2.5.14

> **Найдите все обычные файлы и только их, имена которых не оканчиваются на `.sh`. Файлы без расширения также должны попадать в результат.**

```bash
find . -type f ! -name '*.sh'
```

### 2.5.15

> **Найдите все обычные файлы и только их, у которых количество жёстких ссылок больше двух.**

```bash
find . -type f -links +2
```

### 2.5.16

> **Найдите все обычные файлы в `/usr/bin` и его подкаталогах, сохранённая метка последнего доступа к которым (`atime`) указывает на время более 90 суток назад.**

```bash
find /usr/bin -type f -atime +90
```

### 2.5.17

> **Найдите все обычные файлы в каталогах `/usr/bin` и `/usr/share`, включая их подкаталоги, содержимое которых изменялось в течение последних 10 суток. Используйте время изменения содержимого (`mtime`).**

```bash
find /usr/bin /usr/share -type f -mtime -10
```

### 2.5.18

> **Найдите и удалите все обычные файлы в `/tmp` и его подкаталогах, последнее изменение содержимого которых произошло более 14 суток назад. Используйте время изменения содержимого (`mtime`).**

```bash
find /tmp -type f -mtime +14
sudo find /tmp -type f -mtime +14 -delete
```
